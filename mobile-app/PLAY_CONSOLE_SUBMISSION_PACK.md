## Restricted SMS Permissions Declaration (Draft)

Core functionality:
- CheckPay automatically detects and structures payment transactions from SMS receipts for transaction monitoring and reconciliation.

Why permission is required:
- In supported markets, many payment providers deliver confirmations only through SMS.
- Without SMS import, users must enter transactions manually.

User control:
- SMS auto import is optional.
- App remains usable in manual mode without SMS auto import.
- App prompts for default SMS role before enabling automatic SMS processing.
- If role is not granted, automatic SMS processing remains disabled.

Data handling:
- SMS is processed for transaction extraction.
- Extracted fields are used to create transaction records.
- Data is encrypted in transit.
